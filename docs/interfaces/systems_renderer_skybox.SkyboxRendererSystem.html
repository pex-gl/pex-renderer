            defines: Set<string>;
            uniforms: Uniforms & { uMaterial: UniformBlock };
        }

      • Walks fields against source (material, geometry attributes, any flat bag) in two passes: first collect active defines, then write uMaterial/texture uniforms. Two passes because WGSL struct packing throws on an unknown member, so a field can only write once its define set is final (e.g. specularColor waits on sibling specular). Define-only tables leave uniforms empty.
