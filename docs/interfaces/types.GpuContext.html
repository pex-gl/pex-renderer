    ReadonlyalphaMode

    alphaMode: GPUCanvasAlphaMode

    How the compositor reads the canvas' alpha, as configured. Retained because GPUCanvasContext exposes no getter for it, and anything drawing the final image has to agree: "premultiplied" reads the stored values as already multiplied by alpha, so a renderer writing straight alpha composites too bright, while "opaque" ignores alpha entirely.
