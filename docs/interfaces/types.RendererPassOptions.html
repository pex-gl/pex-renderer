    Interface RendererPassOptions

    What the render pipeline hands a renderer for one pass of one view.

    Passed down to the pipeline hooks (getDefines, getShaderOptions, getVariantKey, getPipelineOptions) rather than stashed on the renderer: a renderer draws several passes per frame and several views per frame, and a field left over from the previous one is a pipeline variant compiled against the wrong pass.
