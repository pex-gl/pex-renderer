    Reflection probe system

    Filters the scene's environment (a skybox's user envMap or its analytic _skyTexture, both equirectangular HDR) into image-based lighting, entirely in compute:

    • Diffuse irradiance projected into L2 spherical harmonics (9 coefficients)
    • Specular radiance prefiltered into a native cubemap mip chain (split-sum)

    Adds to reflectionProbe components:

    • "_reflectionProbe": { specularTexture, irradianceCoefficients, sampler } consumed by the standard renderer's USE_REFLECTION_PROBES bindings.

    update is CPU only. declareReflectionProbes records the probe's outputs and its bake into the frame's graph, once per frame rather than per camera.

        • createPrebakedResources: function
          • createPrebakedResources(data: ReflectionProbePrebakedData): ProbeResources

            Builds probe resources from pre-baked IBL data (e.g. a glTF EXT_lights_image_based light): uploads the file's specular mips and SH coefficients as-is, with no compute-shader bake pass. The mip count comes from the data itself rather than the fixed ROUGHNESS_LEVELS constant, so the specular cubemap's own size is what the shader is told to sample against (see systems/renderer/standard.ts's ROUGHNESS_LEVELS override).
