          • OptionaldepthBias?: number

            Rasterizer constant depth bias, in depth-buffer resolvable units. Negative pulls towards the camera, which is how coincident lines (an axes helper over a grid line) are given a stable winner instead of z-fighting.

          • Optionalemissive?: Color
          • OptionalemissiveExposure?: number

            How much of the camera's exposure the emissive term receives, [0, 1], applied as mix(1.0, exposure, emissiveExposure).

            0 (the default) undoes the exposure — the surface holds its authored screen value whatever the camera does. That is what keeps emissiveStrength a unitless multiplier, meaning the same thing in a physically lit scene and a relative one, and it is how you force a surface to carry on blooming, or keep a decal or HUD element legible.

            1 meters it like any other light, so stopping the camera down dims it as a real source would. Only meaningful if emissive * emissiveStrength was authored as a luminance in cd/m² — a computer display is 200 to 1000, and display white at the default exposure is near 38 000.

          • OptionalemissiveStrength?: number

            Multiplier on emissive, matching glTF's KHR_materials_emissive_strength: 1 puts the authored colour at display white, and higher values are the headroom a bloom pass works from.

          • OptionalemissiveTexture?: MaterialTexture
          • Optionalhooks?: MaterialHooks

            Custom WGSL spliced into the shader that draws this material, and the values its own bindings are fed with.

          • Optionalior?: number
          • lineResolution: number

          • lineWidth: number

          • Optionalmetallic?: number
          • OptionalmetallicRoughnessTexture?: MaterialTexture
          • OptionalmetallicTexture?: MaterialTexture

          • OptionalnormalTexture?: MaterialTexture
          • OptionalnormalTextureScale?: number
          • OptionalocclusionTexture?: MaterialTexture
          • OptionalocclusionTextureStrength?: number
          • perspectiveScaling: boolean

            Whether lineWidth shrinks with distance.

          • OptionalreceiveShadows?: boolean
          • OptionalresponsiveAA?: boolean

            Tell a temporal filter not to trust this surface's history, so it favours the current frame over one reprojected through motion vectors that do not describe it.

            For surfaces that move in ways the vertex stage cannot report: scrolling texture coordinates, an animated normal map, anything driven from time in the shader. Blended and transmissive materials do this already without being asked, since neither is drawn in the pass that writes motion vectors.

            Costs the surface its temporal antialiasing, so it is a trade rather than a fix — set it where ghosting is worse than aliasing.

          • Optionalroughness?: number
          • OptionalroughnessTexture?: MaterialTexture
          • OptionalsgDiffuse?: Color

            Specular-glossiness workflow, from the archived KHR_materials_pbrSpecularGlossiness. Prefixed because the extension's own specularFactor means something else to KHR_materials_specular; setting any of them selects the workflow.

          • emissiveExposure: number

            How much of the camera's exposure the emissive term receives, [0, 1], applied as mix(1.0, exposure, emissiveExposure).

            0 (the default) undoes the exposure — the surface holds its authored screen value whatever the camera does. That is what keeps emissiveStrength a unitless multiplier, meaning the same thing in a physically lit scene and a relative one, and it is how you force a surface to carry on blooming, or keep a decal or HUD element legible.

            1 meters it like any other light, so stopping the camera down dims it as a real source would. Only meaningful if emissive * emissiveStrength was authored as a luminance in cd/m² — a computer display is 200 to 1000, and display white at the default exposure is near 38 000.
